# Draft Prompts

All `.txt` files are editable templates, not validated or frozen experimental prompts. Remove the first-line DRAFT marker when finalizing a template and recompute its hash. Choose chat templates, few-shot examples, and answer formats using development material only, and record them in the protocol.

`jev_final.txt` and `jev_partial.txt` express different judgment targets. Select the partial-draft formulation in Week 5. The actual Jev request/response schema awaits service documentation. Never include references, hidden tests, correctness labels, or oracle outcomes in judge prompts.
